# Hybrid Malware Classification based on API Call Sequence and Network Traffic

Midterm project combining:
- Step 1: Malware classification using API call sequences (Cuckoo/CAPE)
- Step 2: Malware classification using network traffic (.pcap)
- Step 3: Hybrid fusion of both feature types

## Structure
- `code/step1_api_calls/` — API call sequence extraction + model
- `code/step2_network_traffic/` — pcap feature extraction + model
- `code/step3_hybrid/` — fusion model
- `report/` — Word report, PPT, team responsibility table
